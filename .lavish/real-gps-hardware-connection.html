Motorpool Management System

Connect real GPS hardware

A field-ready path for a SinoTrack ST-901/H02 tracker to appear on the MMS live vehicle map. Start with the simulator; configure the tracker only after the entire cloud pipeline passes.

The connection path
Compatibility gate

Use the supported hardware path

This guide is for the SinoTrack ST-901 family that speaks H02 TCP. The tracker never sends HTTP to MMS directly. A non-H02 device needs a gateway decoder before it can connect.

Network gate

Confirm 2G before installation

The common ST-901 is 2G-only. The SIM needs SMS, data, and working 2G coverage where the vehicle operates. Do not mount it permanently until this is confirmed.

1

Set the API key

Generate a secret and set GPS_DEVICE_API_KEY on the API service. Keep it off the web client.

2

Reserve the gateway IP

Create the VM only after reserving its static public IPv4. Trackers are configured with this exact IP by SMS.

3

Run the gateway

Deploy the MMS gateway on the VM, supply the API URL and same secret, then open TCP 5013.

4

Simulate first

Register fake ID 1234567890 and confirm it moves the assigned MMS vehicle before hardware setup.

5

SMS the tracker

Set the carrier APN, the static gateway IP and port 5013, then wait outside for a GPS fix.

6

Register the logged ID

Copy the exact device ID from the gateway warning, activate it for one vehicle, then restart the gateway.

Ready before SMS

Do not proceed until this is true

  • The API rejects a deliberately wrong device key with 401, not 500.
  • The VM IP is reserved and shows IN_USE.
  • The gateway log says it is listening on TCP 5013.
  • The simulator moves an assigned vehicle on the deployed map.
Live hardware proof

All three signals must agree

  • Gateway log: real frames are forwarded; no unregistered or forward failed messages.
  • MMS map: assigned vehicle updates at the physical tracker location.
  • Trackers page: the device is Online. This can lag, so the map is the decisive live signal.

Fast diagnosis

Symptom Most likely cause Next action
No SMS reply SIM or power problem Test the SIM in a phone; check tracker power.
SET OK, no gateway logs APN/data/2G issue or wrong IP Recheck carrier APN; rerun the simulator against the same VM IP.
unregistered/unassigned Wrong or inactive device ID Register the exact ID shown in the log and restart the gateway.
dropping void fix No satellite lock Take the tracker outdoors and wait several minutes.
Speed about 2× wrong Firmware speed unit differs Switch SPEED_UNIT between knots and kmh, then restart.
